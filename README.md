## 역할 개요

| 역할 | 진입 | 핵심 책임 |
| --- | --- | --- |
| 관리자 | 관리자 로그인 | 예약·아티스트·도안·콘텐츠·통계 전체 관리, 시스템 운영 |
| 아티스트 | 아티스트 로그인 | 본인 예약 조회, 본인 도안·프로필 관리, 캘린더 등록 |
| 고객 | 비로그인 | 도안 탐색, 플래시/커스텀 예약, 예약 조회 |

> 로그인 실패 5회 시 계정 잠금. 잠금 해제는 관리자만 가능.

## 예약 상태 흐름 (공통)

세 역할이 공유하는 예약 상태 전이.

```mermaid
stateDiagram-v2
    [*] --> 대기: 고객 예약 완료
    대기 --> 입금확인대기: 고객 입금완료 버튼 클릭
    입금확인대기 --> 확정: 아티스트 캘린더 등록 버튼 클릭
    대기 --> 무응답: 만료 기간 내 채널 연락 없음
    입금확인대기 --> 무응답: 만료 기간 내 채널 연락 없음
    대기 --> 취소: 관리자 처리
    입금확인대기 --> 취소: 관리자 처리
    확정 --> [*]
    무응답 --> [*]
    취소 --> [*]
```

### 1.2 예약 확정 흐름 (슬랙 → 구글 캘린더)

```mermaid
flowchart TD
    A[고객 예약 완료] --> B[상태: 대기]
    B --> C[고객이 입금완료 버튼 클릭]
    C --> D[상태: 입금확인대기]
    D --> E[슬랙으로 아티스트에게 새 예약 알림 전송]
    E --> F["슬랙 알림 카드 — 예약번호 · 날짜 · 도안 · 고객 이메일 · 캘린더 등록 버튼"]
    F --> G[아티스트가 캘린더 등록 버튼 클릭]
    G --> H[슬랙 ID로 아티스트 자동 식별]
    H --> I[해당 아티스트 구글 캘린더 자동 등록]
    I --> J[상태: 확정]
    J --> K[예약가능 달력에서 해당 시간 자동 제거]
```

## 3. 고객 워크플로우

### 3.1 사이트 구조 / 페이지 이동

```mermaid
flowchart TD
    M[메인 화면] --> P1[아티스트 소개]
    M --> P2[플래시도안 목록]
    M --> CALC[미니타투 계산기]
    M --> LOC[타투샵 위치 · 관리법/안내]
    M --> CHK[예약 확인/조회]
    M --> FAQ[FAQ]
    M --> SHOP[샵 상품]
    P1 --> P3[플래시도안 상세]
    P2 --> P3
    P3 --> FLASH[플래시도안 예약 흐름]
    M --> CUSTOM[커스텀 예약 흐름]
    SHOP --> SD[상품 상세] --> EXT[스마트스토어 / 카카오쇼핑 이동]
```

### 3.2 플래시도안 예약 흐름

```mermaid
flowchart TD
    A[플래시도안 상세 페이지] --> B[예약가능 캘린더에서 날짜/시간 선택]
    B --> C[예약하기 클릭]
    C --> D{블랙리스트 고객?}
    D -->|예| E[예약 불가 안내 페이지]
    D -->|아니오| F[구글 이메일 인증]
    F --> G{개인정보처리방침 동의?}
    G -->|미동의| H[예약 진행 불가]
    G -->|동의| I[예약금 안내 — 계좌/페이팔/예약폼]
    I --> J[입금완료 버튼 클릭]
    J --> K[예약 완료 페이지 — 예약번호 발급]
    K --> L[이메일로 예약번호 자동 발송]
    K --> N[채널로 예약번호 + 입금이름 전송 안내]
    N --> O[상태: 대기]
```

### 3.3 커스텀 예약 흐름 (8단계)

```mermaid
flowchart TD
    S0[커스텀 예약하기 시작] --> CK{블랙리스트 고객?}
    CK -->|예| BL[예약 불가 안내 페이지]
    CK -->|아니오| S1[1단계 · 아티스트 선택]
    S1 --> S2[2단계 · 타투 장르 선택]
    S2 --> S3[3단계 · 부위 선택]
    S3 --> S4[4단계 · 크기 선택]
    S4 --> S5[5단계 · 성별 선택]
    S5 --> S6[6단계 · 나이대 선택]
    S6 --> S7[7단계 · 원하는 날짜 선택]
    S7 --> S8[8단계 · 이메일 입력 + 개인정보처리방침 동의]
    S8 --> DONE[완료 — 예약번호 발급 + 연락채널 안내]
    DONE --> SLACK[슬랙으로 아티스트에게 정보 자동 전달]
    S8 -. 이전 단계로 돌아가기 .-> S1
    S2 -. 뒤로가기 시 예약 취소 확인 .-> S0
```
